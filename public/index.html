    Configurações

    O estudo com IA usa o Claude, e para isso o app precisa da sua chave da API.

    1. Entre em console.anthropic.com e crie uma conta, se ainda não tiver.
    2. Em Billing, adicione um pouco de crédito.
    3. Em API Keys, clique em Create Key e copie a chave. Ela começa com sk-ant-.
    4. Cole a chave abaixo e toque em Salvar.

    A chave fica guardada só neste aparelho (no navegador). Ela não vai para o GitHub nem para mais ninguém. Não compartilhe a chave com outras pessoas.
